Every table on this site as CSV, plus the game-level file everything is built from.

All files are regenerated on every build from the scripts in the repository. The game-level file (games_adjusted.csv) has one row per regular-season game with the adjusted home margin, week index, season phase, and each side's playoff situation entering that week. Source data: FiveThirtyEight (MIT license) for 1970-1998 and nflverse (CC BY 4.0) for 1999 onward, merged and transformed as described on the methodology page.
