# Home Field Advantage (side study)

How much is playing at home worth in the NFL, 1970-2025, and does it fade
late in the season? Published as a sub-site of Gridiron Greatness Rating at
https://1eyebiney.github.io/gridiron-greatness-rating/home-field-advantage/

Questions it answers, from final scores alone:

- How many points home field is worth, by decade (it has fallen from about
  3 points to under 2).
- Whether it fades as the season goes on (no - the final third is the
  strongest part, in five of six decades and tied in the sixth).
- Whether teams out of the playoff race lose their home edge, as the
  resale-ticket hypothesis predicts (no measurable effect, once a
  selection artifact is handled properly).
- What the crowd is worth (the 2020 season, without fans, had none).
- Whether any franchise's fans travel well enough to show up in the scores
  (no franchise is distinguishable from the league average).

## Layout

    data/raw/nflverse/       nflverse games.csv for roof / division flags and the current season (SOURCE.md)
    data/processed/          every table the site shows, as CSV (regenerated by src/hfa.py)
    src/hfa.py               the analysis
    src/hfa_site.py          the site generator (Jinja2 templates in src/site_templates/)
    src/hfa_build.py         runs both
    tests/                   unit tests, whole-site link checker, and narrative-claim checks
    docs/NOTES.md            design notes and decisions

The unified games table, conference table and franchise crosswalk are read
from the main repository (`../../data/`), not copied.

## Run it

From the repository root:

    python studies/home-field-advantage/src/hfa_build.py     # tables and a standalone site/ here
    PYTHONPATH=studies/home-field-advantage/src python -m pytest studies/home-field-advantage/tests -q

The main site build (`python src/run_phase6.py`) also renders this study
into `site/home-field-advantage/`, which is what GitHub Pages publishes.
